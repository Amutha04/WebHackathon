🧠 Nutrimind is a feature-rich web application built using HTML, CSS, and JavaScript to support users on their health and wellness journey. It includes a personalized dashboard for tracking daily nutrient intake, a secure login/logout system, and a toggleable light/dark mode for a better user experience. Key features include a Discussion Forum for community engagement, a Journal for tracking meals and progress, and a Settings section for customizing notifications, privacy, and interface preferences. Nutrimind combines functionality and design to help users stay mindful, connected, and in control of their wellness goals.
